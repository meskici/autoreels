## Voiceover

Not synthesised. There is no Turkish voice available in this container —
Kokoro, the local model, has no Turkish, and no ElevenLabs key is set. That is
the smaller reason. The larger one is in the brand profile: *"One person
talking out loud, in Turkish, to one other person. Mert makes every lamp
himself, so first person singular is the brand's real voice."* A synthetic
read is off-brand for this voice whether or not a Turkish model is available.

The five lines above are timed to be read over the cut as it stands.

## Checked against the brand profile

- No banned word, no superlative, no discount or urgency framing, price never mentioned.
- Opens on what the viewer can see, not on the product name.
- Present continuous throughout, not the written aorist. One particle (*bak*).
- One question in the piece, at the close.
- No three-item list; a two-word fragment sits next to a long sentence.
- Never claims the object is carved, joined or worked from wood; never names the production method.
- Uses the description's own verbs — *taşıyor* over a stronger one, *büyüyor / yumuşuyor* as written.

## What the visuals are, and are not

The lamp here is **drawn, not photographed**. The six real product photos live
on `cdn.shopify.com`, which this container's egress policy denies.

The form is not invented, though. It is built to the published spec, pulled
live from Shopify (`gid://shopify/Product/9218316861697`):

| Spec | Value | How the drawing uses it |
|---|---|---|
| Boyutlar | **Y21 × G11 × D11 cm** | square-section column, front face 11cm wide over a 19cm body, 1:1.73 — not a tapered shade |
| Malzeme | PETG + PLA, mat dokulu | flat matte panels, no wood grain on the body |
| Taban | "ahşap görünümlü taban" (image alt text) | wood-toned base only, and the copy never claims wood |
| Duy | E27 · 5W LED **2700K** | the warm glow temperature in the lit half |

A first cut drew a tapered lampshade. That was wrong — the series is flat-panel
work ("kumiko marangozluğu düz panelde çalışır: kapı kanatları, paravanlar,
kutu lambalar", from the sibling Kumiko.Tetra listing) and the dimensions say
square column. The spec settled it.

The asanoha lattice is *constructed* in `build.py`, not drawn by hand and not
generated by a model: a triangular lattice in which every triangle contributes
three centroid-to-vertex arms. That is the hemp-leaf figure, and it is exact at
any zoom. This matters because of the brand's own warning — image-to-video
models "redraw it between frames and the motif comes out wrong, which is the
one thing this brand cannot ship." Constructed geometry cannot drift.

It is still an illustration built to the measurements, not the object itself.
For a cut built on the real photography, render on a GitHub Actions runner,
which can reach the CDN.
